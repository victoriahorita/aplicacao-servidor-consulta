# Consulta de Pessoas - Full Stack

Aplicação Full Stack desenvolvida para consulta de dados cadastrais
por CPF, nome e similaridade de nome.

## Tecnologias

- Python
- Flask
- Gunicorn
- HTML
- CSS
- JavaScript
- SQLite3
- Docker
- Docker Compose

## Estrutura

- backend: API Flask
- frontend: interface web
- db: banco de dados SQLite3
